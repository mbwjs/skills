# skills

Reusable Muse skills: prompt systems and camera language for AI video generation.

## Skills

- **fight-camera/** — High-speed fight cinematography camera language: 10 camera formulas, 4 speed tiers (Swift / Whip / Gentle / Shock), and shot-size pairings for martial-arts and action scenes. The full Chinese manual lives in `fight-camera/references/fight-camera-manual.md`.

## Usage

Each skill directory contains a `SKILL.md` describing when to trigger it and how to apply it. Copy a skill directory into your own Muse workspace under `~/workspace/skills/` to use it.
